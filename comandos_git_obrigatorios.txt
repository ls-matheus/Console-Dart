=== COMANDOS GIT OBRIGATÓRIOS PARA A ENTREGA ===

O repositório local já foi inicializado e os commits iniciais foram realizados.
Os comandos necessários para enviar o código para o repositório remoto no GitHub são:

1º Passo) Conectar o código local com o repositório no GitHub:
git remote add origin https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git

2º Passo) Garantir que a branch principal se chama "main":
git branch -M main

3º Passo) Enviar o código para o GitHub (Push):
git push -u origin main
