# Sistema de Biblioteca em Dart

Uma aplicação simples de console para gerenciar uma biblioteca, feita em Dart.

## Como executar

1. Certifique-se de ter o [Dart SDK](https://dart.dev/get-dart) instalado na sua máquina.
2. Clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:
   ```bash
   dart run
   ```

## Funcionalidades

- Cadastrar livros
- Listar livros
- Pesquisar livro pelo título
- Emprestar livro
- Devolver livro
- Remover livro
