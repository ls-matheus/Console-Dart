=== TODOS OS COMANDOS BÁSICOS DO GIT ===

Aqui estão os principais comandos do Git que você pode usar no dia a dia como desenvolvedor:

1. CONFIGURAÇÃO (Configurar quem é você no Git)
git config --global user.name "Seu Nome"
git config --global user.email "seu.email@exemplo.com"

2. INICIALIZAÇÃO E CLONAGEM (Começar um projeto)
git init            -> Inicia um novo repositório Git na pasta atual.
git clone [url]     -> Baixa um repositório da internet para a sua máquina.

3. ESTADO E MUDANÇAS (Ver o que mudou)
git status          -> Mostra os arquivos que foram modificados, adicionados ou excluídos.
git diff            -> Mostra as diferenças exatas no código dos arquivos modificados.

4. ADICIONAR E COMMITAR (Salvar as alterações)
git add .           -> Adiciona todos os arquivos modificados/novos para serem salvos (na área de stage).
git add [arquivo]   -> Adiciona um arquivo específico.
git commit -m "msg" -> Salva (faz o commit) das alterações com uma mensagem explicativa ("msg").

5. HISTÓRICO (Ver o que já foi feito)
git log             -> Mostra o histórico de commits do projeto.
git log --oneline   -> Mostra o histórico de forma resumida, apenas com os IDs e mensagens.

6. RAMIFICAÇÕES (Branches)
git branch          -> Lista as branches (ramificações) do projeto.
git branch [nome]   -> Cria uma nova branch.
git checkout [nome] -> Troca para a branch especificada.
git merge [nome]    -> Junta o código da branch especificada com a branch em que você está.

7. SINCRONIZAÇÃO (Enviar e receber dados do GitHub)
git remote add origin [url] -> Conecta seu projeto local a um repositório remoto (ex: GitHub).
git push -u origin main     -> Envia seus commits para o GitHub pela primeira vez.
git push                    -> Envia seus commits para o GitHub (depois da primeira vez).
git pull                    -> Baixa as alterações do GitHub para a sua máquina.
git fetch                   -> Apenas baixa as informações do GitHub, mas não mistura com seu código local.
